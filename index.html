Privacy policy

Updated 7 October 2026.

The integration is operated by GitHub user nycho1986 for their own personal use. Its intended purpose is to retrieve authorized Oura sleep, activity, readiness, heart-rate and blood-oxygen data for a personal logbook and user-requested analysis.

Authorization takes place with Oura. The integration does not request or store the Oura account password. Access credentials and downloaded records are to be kept in private local storage, outside this public repository and website.

This public website has no health-data upload form, advertising, analytics scripts or application cookies. GitHub Pages hosts it and may process technical request information under GitHub's privacy statement.

When the owner requests analysis using Codex, relevant data may be processed by OpenAI under the owner's account settings and OpenAI's privacy policy. The workflow therefore is not exclusively offline. Files placed by the owner in a synced folder may also be stored by that folder's cloud provider.

The project does not publish health records or sell them. Local records are retained until the owner deletes them. Revoking access in Oura stops future authorized retrieval but does not erase already downloaded files, chat history or backups; those must be managed separately in the relevant services.

Terms of use

This project is intended solely for its owner's personal, non-commercial use. It does not offer a public account-registration service or accept other people's health records.

It provides information for personal reflection, not medical diagnosis or treatment. Measurements and generated interpretations may contain errors. The owner should check original records and seek qualified care for medical decisions.

This is an independent project, not an official Oura or OpenAI product. Use of Oura, GitHub and OpenAI remains subject to their respective terms. These project notes do not replace those terms.
